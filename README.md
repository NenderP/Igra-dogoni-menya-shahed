# Карточная игра (рабочее название)

Дуэльная карточная игра в духе «Гения Призыва» из Genshin Impact + гача-система коллекционирования. Только под мобилки (Android, APK).

## Боевая система

- Вместо элементов — **времена суток**: Рассвет, День, Затмение, Сумерки, Ночь (5) + универсальный дайс = 6 граней
- Дайсы как в Геншине: бросок в начале раунда, трата на действия
- **Реакции = только чистый урон** (без дебаффов): пары времён дают бонус урона
  - День + Ночь → Сумерки (+урон)
  - Рассвет + Затмение → Золотой час (×2)
- **В начале каждого раунда выдаются карточки поддержки** (как саппорт-карты в Геншине)
- В отряде **3 персонажа**, смена персонажей и энергия — как в Геншине

## Гача и коллекция

- Редкость: **3★ / 4★ / 5★**
- Шансы: 5★ = 0.6%, 4★ = 5.1%; **хард-пити 90, софт-пити с 75, гарант после проигранного 50/50**
- **Дубли → пыль** (3★ = 5, 4★ = 25, 5★ = 100), **50–75 пыли = 1 крутка**
- Первая версия: **8 персонажей** — 2 легендарки (5★), 4 эпика (4★), 2 рарки (3★)

## Боты

- 3 уровня сложности: у лёгкого простые колоды и простой ИИ, у сложного — колоды на комбо и умный ИИ
- Колоды ботов всегда рандомные

## Мультиплеер

- Бой с другом по лобби-коду или матчмейкинг со случайным соперником
- Соло против ботов
- **Server-authoritative**: честные броски дайсов и вся логика на сервере
- Сервер: Ubuntu-ноут дома, доступ в интернет через бесплатный туннель (ngrok / Cloudflare Tunnel) — игра через мобильный интернет
- Сообщения — лёгкий JSON

## Технологии

- Клиент: **C# + MonoGame** → APK для Android
- Сервер: C# (решение уточним при старте)
- Эффекты: шейдеры MGFX, частицы (MonoGame.Extended / Nez), твининг анимаций, FMOD/NAudio, Myra для UI
- Без браузера, без VPS

## Процесс разработки

- Двое разработчиков, каждый вайбкодит в opencode на своём ноуте
- Параллельная работа по модулям: серверная логика боя / гача и аккаунты / клиент
- Общение агентов — через war-room файл в репозитории
