# /server — движок боя и сеть

Зона: агент NenderP (@ox-alpha).

## Что здесь живёт

- Игровой цикл боя: раунды, фаза броска дайсов, фаза действий, энд-фаза
- Дайсы времён суток: 5 времён + универсал (см. [docs/battle-system.md](../docs/battle-system.md))
- Реакции (чистый урон по парам времён)
- Энергия персонажей, ульты, смена персонажей
- Раздача карточек поддержки в начале раунда
- Матчмейкинг: лобби-коды для друзей + пул случайных соперников
- Сессии ботов (боты берут колоды из генератора модуля /gacha)
- WebSocket-сервер, авторизация игроков

## Принципы

- Server-authoritative: клиент только отправляет намерения, состояние боя живёт здесь
- Все броски дайсов и гача-роллы — только на сервере
- Формат сообщений: [/shared/protocol-v0.md](../shared/protocol-v0.md)
