# /client — MonoGame клиент (Android APK)

Общий модуль. Экраны делятся по принадлежности фичи:
боевой экран — серверная команда (@ox-alpha), гача/коллекция — команда гачи (@kinder-joy228).

## Целевой стек

- C# + MonoGame (pygame-ce аналог: MonoGame.Extended, Nez — частицы/твининг; Myra — UI; FontStashSharp — шрифты)
- Сборка APK под Android
- Связь с сервером: WebSocket, JSON ([/shared/protocol-v0.md](../shared/protocol-v0.md))

## Планируемые экраны

1. Главное меню → вход/регистрация
2. Лобби: соло против бота (3 сложности) / игра с другом по коду / поиск рандома
3. Бой: поле 3×3 персонажей, дайсы, рука карт, карты поддержки
4. Гача: баннер, анимация крутки (частицы + свечение по редкости)
5. Коллекция: сетка персонажей, детали, пыль/конвертация
