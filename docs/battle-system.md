# Боевая система — зафиксированные решения

## Времена суток (вместо элементов)

| Грань дайса | Код | Идея |
|---|---|---|
| Рассвет | `dawn` | исцеление/усиление |
| День | `day` | прямой урон |
| Затмение | `eclipse` | тёмный урон, риск |
| Сумерки | `twilight` | хитрость, комбо |
| Ночь | `night` | криты/энергия |
| Универсал | `omni` | платит за что угодно |

Бросок: **8 дайсов на раунд** (как в Геншине). Цифры количества/шансов — БАЛАНС-TBD, меняем плейтестами.

## Реакции (только чистый урон, без дебаффов)

| Пара | Название | Эффект |
|---|---|---|
| День + Ночь | Сумерки | +N урона (N = БАЛАНС-TBD, стартово 2) |
| Рассвет + Затмение | Золотой час | урон ×2 (по согласованию) |
| Ночь + Затмение | Полная тьма | +N урона (TBD) |
| Сумерки + Рассвет | Заря | +N урона (TBD) |

Прочие пары — без реакции. Список может расшириться, изменения фиксируем здесь.

## Раунд (порядок фаз)

1. **Раздача**: каждому игроку выдаётся карта поддержки (в начале раунда)
2. **Бросок**: оба игрока кидают дайсы (есть переброс части, как в Геншине)
3. **Действия**: по очереди — сыграть карту / скилл персонажа / сменить персонажа / конец хода
4. **Энд-фаза**: тик энергии, проверка смертей персонажей, добор

## Персонажи

- В отряде 3 персонажа, у каждого: HP, элемент(время), базовый удар, скилл, ульта (энергия)
- Смерть всех трёх = поражение
- Пул v1: 2×5★ (легендарки), 4×4★ (эпики), 2×3★ (рарки)

## Открытые балансные вопросы (решают люди, не агенты)

- Точные цифры реакций N
- Стоимость скиллов в дайсах и пороги ульты
- HP-пулы персонажей
- Сколько карт поддержки максимум на поле одновременно
