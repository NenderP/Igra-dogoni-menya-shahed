# AGENTS.md — правила работы агентов над проектом

Карточная игра в духе «Гения Призыва» (Genshin TCG) + гача. Только мобилки (Android APK).
Полная концепция — в [README.md](README.md). Это краткая выжимка + правила совместной работы.

## Стек

- Клиент: C# + MonoGame → APK
- Сервер: C#, server-authoritative (все броски дайсов и логика боя на сервере)
- Связь: JSON-сообщения через туннель (ngrok/Cloudflare) на сервере дома у NenderP
- Репозиторий: https://github.com/NenderP/Igra-dogoni-menya-shahed

## Кто за что отвечает (НЕ трогать чужие модули без договорённости в WAR_ROOM.md)

| Модуль | Владелец | Содержание |
|---|---|---|
| `/server` | **NenderP + его агент** | Движок боя: дайсы, времена суток, реакции, ходы, энергия; сетевой протокол; лобби и матчмейкинг |
| `/gacha` | **друг NenderP + его агент** | Гача: баннеры, пити, шансы; аккаунты, коллекция, инвентарь, пыль; боты (3 сложности, рандомные колоды) |
| `/client` | общий | Экраны делятся по принадлежности фичи: боевой экран — серверная команда, гача/коллекция — команда гачи |
| `/shared` | общий, только по договорённости | Схемы JSON-сообщений между клиентом и сервером |
| `/docs` | общий | Документы, дизайн |

## Обязательный ритуал каждого рабочего захода

1. **В начале**: прочитай [WAR_ROOM.md](WAR_ROOM.md) — там статус, планы и вопросы второго агента
2. **Работай** только в своих модулях (таблица выше)
3. **В конце**: оставь запись в WAR_ROOM.md по формату ниже
4. Коммить маленькими порциями с префиксом модуля: `server: ...`, `gacha: ...`, `client: ...`, `shared: ...`, `docs: ...`

## Формат записи в WAR_ROOM.md

```
## ГГГГ.ММ.ДД ЧЧ:ММ — @ник_агента (модуль)
Сделал: ...
Делаю: ...
Дальше: ...
Вопросы к тебе: ...
```

## Правила общения между агентами

- Спорные решения (схемы сообщений, интерфейсы между модулями) — обсуждаем записями в WAR_ROOM.md, а не меняем чужой код молча
- Не морочь человека вопросами, на которые есть очевидный стандартный ответ — решай сам в рамках своего модуля
- К человеку выносим только: название игры, балансные цифры, визуальный стиль, всё что меняет концепцию из README.md
- Если блокируешь второго агента (нужен его интерфейс) — пометь запись в WAR_ROOM тегом `[БЛОКЕР]`
